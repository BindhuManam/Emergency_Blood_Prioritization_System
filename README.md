# Emergency_Blood_Prioritization_System
A Python based Emergency Blood Requirement Prioitization System that helps hospitals manage urgent blood requests,prioritize patients based on emergency levels, and match suitable blood donors.Built using Python and  JSON for simple and efficient data management.
# 2. Features
- Donor Registration: Register donors with name, age, blood group and city.
- Hospital Request Registration: Hospitals can register their blood requirements.
- Blood Group Matching: Find donors with a matching blood group.
- Request Prioritization: Manage emergency blood requests based on priority.
- Data Storage: Save donor and request details using JSON.
- Data Persistence: Previously saved information can be loaded when the program starts.

## 3. Technology Stack
- Programming Language: Python
- Data Storage: JSON
- Built-in Python Modules: json, os
- Code Editor: Visual Studio Code
- Version Control: Git and GitHub

## 4. Setup and Run Commands

### Requirements
- Python 3 installed
- Visual Studio Code
- Git installed

### Steps to Run

1. Clone the repository:

   git clone https://github.com/BindhuManam/Emergency_Blood_Prioritization_System.git

2. Open the project folder:

   cd Emergency_Blood_Prioritization_System

3. Run the Python program:

   python main.py

4. Follow the instructions displayed in the terminal.

## 5. Environment Variables
This project does not require any environment variables or external configuration.

## 6. API or Database Notes
- This project does not use external APIs.
- No SQL or external database is required.
- JSON is used to store donor and hospital request information.
- The data is stored locally in the blood.json file.
- Python's json module is used to read and write data.

The Emergency Blood Prioritization System provides a simple way to manage blood donors and emergency hospital requests. It aims to make donor identification and emergency blood management easier and more organized.
